= Каталог блоков

Повторяет группы «Показать → Блоки» прототипа: на этой странице проверяют вид блоков в Светлой и Тёмной темах. Все данные придуманы.

== Заголовки

=== Подраздел третьего уровня

Абзац с отметками: *жирный*, _курсив_, `код`, [.line-through]#зачёркнутый# и [.hl-yellow-bg]#выделение#.

== Цвет текста и заливка

Цвет текста: [.hl-red]#красный#, [.hl-blue]#синий#, [.hl-green]#зелёный#, [.hl-gray]#серый#. Заливка: [.hl-yellow-bg]#жёлтая#, [.hl-green-bg]#зелёная#, [.hl-blue-bg]#голубая#, [.hl-pink-bg]#розовая#, [.hl-purple-bg]#фиолетовая#, [.hl-gray-bg]#серая#.

== Предупреждения

NOTE: Примечание абзацем: полоса слева и ярлык цвета типа.

TIP: Совет абзацем.

IMPORTANT: Важно абзацем.

WARNING: Внимание абзацем.

CAUTION: Осторожно абзацем.

[NOTE]
====
Примечание блоком со списком:

* первый пункт
* второй пункт
====

== Списки

* маркированный пункт
* ещё один

. нумерованный пункт
. следующий

* [ ] пункт чек-листа
* [x] выполненный пункт

имя: метеостанция
режим: [день, ночь]
