= Таблицы

Абзац над таблицей. Его можно править в визуальном редакторе: таблица от этого не меняется.

== Строки и заголовок

.Заказы
[cols="1,3,1",options="header"]
|===
|Номер |Описание |Сумма

|1001
|Личный кабинет клиента
>|120

|1002
|Приложение для курьеров
>|80
|===

Первая строка таблицы без `options="header"` и с пустой строкой после неё сама становится заголовком:

|===
|Статус |Срок

|Принято
|день

|В работе
|неделя
|===

== Объединения и выравнивание

[cols="1,1,1",frame=ends,grid=rows,stripes=even]
|===
3+^.^s|Итоги квартала

.2+|Кабинет
|Заказы
>m|1 204

|Оплаты
>m|987

|Итого 2*|повторяется
|===

== Другие форматы

Запись через запятую:

[%header,format=csv]
|===
Товар,Цена,"Комментарий, с запятой"
Хлеб,50,свежий
Молоко,90,"холодное ""из погреба"""
|===

Запись через двоеточие и свой разделитель:

[format=dsv]
|===
Имя:Роль
Анна:дизайнер
Борис:разработчик\: и редактор
|===

[separator=¦]
|===
¦раз ¦два
¦три ¦четыре
|===

== Ячейки с блоками

Ячейка со стилем `a` читается как отдельный документ: в ней списки, блоки кода и вложенные таблицы.

[cols="1,2a"]
|===
|Список
|
* первый пункт
* второй пункт
+
Присоединённый абзац.

|Код
|
[source,json]
----
{"ok": true}
----

|Вложенная таблица
|
Внутри ячейки:

!===
!Ключ !Значение

!цвет
!синий

!размер
a!
Ещё одна вложенная таблица:

,===
a,b
c,d
,===
!===
|===

Абзац под последней таблицей.
