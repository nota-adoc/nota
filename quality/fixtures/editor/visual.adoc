= Техническое задание: личный кабинет клиента

== Цель

Сделать *личный кабинет*, в котором клиент видит свои _заказы_, их статусы и `номера накладных`.
Срок — **до конца квартала**, приоритет высокий: без кабинета клиенты пишут в поддержку.

== Требования

Кабинет открывается по адресу https://cabinet.example.org и работает в двух режимах: [.line-through]#вход по паролю# и #вход по коду#.

Подробности — в разделе <<acceptance,приёмка>>, в документе xref:glossary.adoc#terms[глоссарий] и на странице link:legal/policy.html[политика данных].
Вопросы — на mailto:help@example.org[почту поддержки] или на <https://example.org/faq>.

=== Экраны

Первая строка абзаца
вторая строка того же абзаца +
и строка после переноса.

* Вход
* Список заказов
* Карточка заказа

=== Пример запроса

Запрос уходит на адрес *POST* `/api/orders`, в ответе — статус заказа:

[source,json]
----
{"order": 42, "status": "shipped"}
----

==== Поля ответа

Поле `status` — одно из значений _new_, _paid_, _shipped_ или __done__.

[[acceptance]]
== Приёмка

Кабинет принят, когда клиент из тестовой группы видит заказы **и** может открыть карточку любого из них.
