= Цвета в тексте

Цвет букв: [.hl-red]#красный#, [.hl-blue]#синий#, [.hl-green]#зелёный#, [.hl-gray]#серый#, [.hl-orange]#оранжевый#, [.hl-purple]#фиолетовый#, [.hl-pink]#розовый#, [.hl-teal]#бирюзовый#.

Роли не из реестра: [.hl-yellow]#a#, [.hl-cyan]#b#, [.hl-orange-bg]#c#.

== Заголовок [.hl-orange]#оранжевый# [.hl-purple]#фиолетовый# [.hl-pink]#розовый# [.hl-teal]#бирюзовый#

* пункт [.hl-orange]#оранжевый#, [.hl-purple]#фиолетовый#, [.hl-pink]#розовый#, [.hl-teal]#бирюзовый#

|===
|Ячейка

|[.hl-orange]#оранжевый# [.hl-purple]#фиолетовый# [.hl-pink]#розовый# [.hl-teal]#бирюзовый#
|===

Заливка: [.hl-yellow-bg]#жёлтая#, [.hl-red-bg]#красная#, [.hl-orange-bg]#оранжевая#, [.hl-green-bg]#зелёная#, [.hl-teal-bg]#бирюзовая#, [.hl-blue-bg]#синяя#, [.hl-pink-bg]#розовая#, [.hl-purple-bg]#сиреневая#, [.hl-gray-bg]#серая#.

== Цвет и pass:q[…]

Текст [.hl-red]#до pass:q[*жир* и _кур_] после#.

Цвет внутри: Текст pass:q[[.hl-red\]#красное#] дальше.

== Цвет и ((указатель))

Текст [.hl-red]#до ((термин)) после#.

== Раздел [.hl-red]#((термин))#

Ссылка: https://example.org[[.hl-red]#pass:q[раз]#] и ещё https://example.org[[.hl-blue]#((два))#].

== Что остаётся плашкой

Все они внутри цвета: [.hl-red]#pass:[<b>раз</b>] pass:c[два] pass:q,c[три] +четыре+ ++пять++ +++<i>шесть</i>+++ $$семь$$#.

Указатели: [.hl-blue]#(((скрытый))) indexterm:[второй] indexterm2:[третий] ((*жирный*))#.
