= Checklists and callouts

== Checklists

* [x] done
* [ ] not done
* [*] starred
** [x] nested done
** [ ] nested open
* plain item

- [x] with hyphen

* [x]
* [X] upper case is text
* [] empty box is text
*[x] no space is not a list
