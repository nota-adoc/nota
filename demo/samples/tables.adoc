= Tables

A paragraph above the table. It can be edited in the visual editor: the table does not change from that.

== Rows and a header

.Orders
[cols="1,3,1",options="header"]
|===
|Number |Description |Amount

|1001
|Customer account page
>|120

|1002
|Courier application
>|80
|===

The first row of a table without `options="header"` and with an empty line after it becomes the header by itself:

|===
|Status |Term

|Accepted
|a day

|In progress
|a week
|===

== Other formats

A comma-separated record:

[%header,format=csv]
|===
Item,Price,"Remark, with a comma"
Bread,50,fresh
Milk,90,"cold ""from the cellar"""
|===

A colon-separated record and a custom separator:

[format=dsv]
|===
Name:Role
Ann:designer
Bob:developer\: and editor
|===

[separator=¦]
|===
¦one ¦two
¦three ¦four
|===

== Cells with blocks

A cell with the style `a` is read as a separate document: it holds lists, code blocks and nested tables.

[cols="1,2a"]
|===
|List
|
* first item
* second item
+
An attached paragraph.

|Code
|
[source,json]
----
{"ok": true}
----

|Nested table
|
Inside the cell:

!===
!Key !Value

!color
!blue

!size
a!
One more nested table:

,===
a,b
c,d
,===
!===
|===

A paragraph under the last table.
